Voice transcription

Checking…

Adds exact-reference transcripts to saved voice samples using SenseVoiceSmall. Install this tool separately; reinstalling Qwen, VoxCPM, or the core app does not install it.

memoryCPU only · no GPU memory · isolated dependencies

How it works

Installation downloads the CPU runtime and pinned model files. Then open Voices → Voice prompts, select a sample's More actions → Generate transcript, or transcribe selected samples in bulk. Review the result for names and unusual words.

Each request runs locally in a short-lived worker that exits and releases its model when finished. Removing this tool keeps your voices, saved transcripts, projects, and generated audio. No cloud API key or backend restart is required.

Welcome to TTS-Story

TTS-Story is installed and ready. Voice engines are now optional, so you can install or configure only the ones you plan to use.

  1. Open Settings → Engines.
  2. Choose a local engine and click Install engine, or enter the credentials required by a cloud or self-hosted engine.
  3. Click Save settings. Ready engines turn green and appear in the Generate page engine list.

Local model files may download during installation or the first generation. Large engines can take several minutes.

The first run can take several minutes and may appear quiet while files download or models load. Keep TTS-Story running and monitor the Job Queue. Later generations with this engine should start much faster.

Generate voices

Design voices for speakers that still need preparation. Ready speakers are skipped by default and pending auditions are kept. Gemini requires the dedicated TTS API key and creates billable hosted voices.

Up to four concurrent candidates per speaker. Speakers run sequentially; Pause finishes the current speaker first. Pending Gemini auditions are kept without new charges. Speakers with a previously selected Gemini candidate receive a new audition; their current voice stays assigned until a replacement is chosen. Google chooses the preview passage. Open each speaker in the Cast list to select its voice, even for a single candidate. Hosted voices require Gemini for narration.

A single candidate is assigned automatically when compatible with the narration engine, including Gemini. With multiple candidates, open the speaker in the Cast list to choose one.
